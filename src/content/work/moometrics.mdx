## Context

Farm workers record animals and deaths in the field, where the signal is weak. Managers need
records that stand up to audits and insurance claims.

## Decisions

<Note kind="decision">
  A death report needs a photo, and the same photo can't be used twice. Images are hashed on the
  device and checked for duplicates.
</Note>

Reusing an old photo is the cheapest way to fake a loss, so it's the first thing to close. Each
animal gets one death record, which can't be edited.

## Build

Records made offline queue on the device and sync on reconnect. Each farm's data is isolated,
and in production the server refuses to start with weak secrets. CI enforces 85% test coverage
and security scans.

## Where it stands

A deployable prototype. Next it needs a real farm for a season.
